Hernán Performance Lab – Privacy Policy

Last updated: October 1, 2026

1. Overview

Hernán Performance Lab is a personal application used to analyze health and training data for athletic performance purposes.

2. Data accessed

With the user's authorization, the application may access data from WHOOP, including recovery, cycles, sleep, workouts, profile information, and body measurements.

3. Use of data

WHOOP data is used exclusively for personal training analysis, performance monitoring, and related athletic purposes.

4. Data sharing

The application does not sell WHOOP data or use it for advertising. Data is not intentionally shared with third parties except where necessary to provide the functionality explicitly requested by the user.

5. Data security

Reasonable measures are taken to protect authorized data and authentication credentials.

6. Revoking access

The user may revoke the application's access to WHOOP data at any time through their WHOOP account settings.

7. Contact

For questions regarding this privacy policy, please contact the application owner through the contact information associated with this application.
